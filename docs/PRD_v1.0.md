## 1. 개발 목적

### 1.1 문제 정의

| 문제 | 설명 |
|------|------|
| **AI 불투명성** | 사용자는 AI가 왜 이런 답변을 했는지 알 수 없음 |
| **기억 상실** | AI는 이전 대화 맥락을 기억하지 못함 |
| **통제 불가** | 사용자가 AI의 사고 과정에 개입할 수 없음 |

### 1.2 해결 목표

**"AI의 사고 과정과 기억을 시각화하고, 사용자가 개입할 수 있는 투명한 AI 챗봇"**

| 목표 | 설명 |
|------|------|
| **시각화 (See)** | AI가 참조한 기억, 사고 단계를 눈으로 확인 |
| **통제 (Control)** | AI의 계획을 수정하고, 잘못된 기억을 삭제 |
| **투명성 (Transparent)** | AI의 신뢰도를 명시하여 환각 대응 |

---

## 2. 제품 특징

### 2.1 핵심 컨셉: "Glass Box"

AI를 블랙박스가 아닌 **투명한 유리 상자**로 만들어 내부를 보여줌

### 2.2 기술적 제약

| 항목 | 제약 |
|------|------|
| **백엔드** | 구현하지 않음 |
| **데이터** | 더미데이터로 시나리오 구현 |
| **API** | 시뮬레이션 (setTimeout + Mock 응답) |
| **상태** | 클라이언트 전용 (localStorage) |

### 2.3 UI 구조

```
┌─────────────────────────────────────────────────────────────┐
│                        헤더                                  │
│  [로고]                ─────────── [설정] [사용자]              │
├────────────┬───────────────────────────┬────────────────────┤
│            │ 채팅명           페르소나 선택 │                    │
│ 워크스페이스  │      GLASSY 채팅            │    GLASS_BOX      │
│   패널      │       (메인)               │      패널           │
│            │                           │                    │
│  280px     │        flex: 1            │      320px         │
│            │                           │                    │
└────────────┴───────────────────────────┴────────────────────┘
```

### 5.1 성능

| 항목 | 요구사항 |
|------|----------|
| **스트리밍** | 모든 텍스트 생성은 토큰 단위 스트리밍 |
| **Optimistic UI** | 메모리 수정/삭제 시 즉시 UI 반영 |
| **TTFT** | 첫 토큰까지 체감 시간 최소화 |

### 5.2 인터랙션 피드백

| 액션 | 피드백 |
|------|--------|
| 저장 | "저장되었습니다" 토스트 |
| 삭제 | "삭제되었습니다" 토스트 |
| 오류 | "오류가 발생했습니다" 토스트 |

### 5.3 반응형

| 화면 크기 | 레이아웃 |
|----------|----------|
| < 768px | 단일 패널 + 하단 탭 |
| 768px ~ 1024px | 2패널 (워크스페이스 숨김) |
| > 1024px | 3패널 풀 레이아웃 |

## 7. 용어 정의

| 용어 | 정의 |
|------|------|
| **GLASSY** | 제품명 |
| **GLASS_BOX** | 우측 메모리 관리 패널 |
| **페르소나** | AI의 역할/성격 프리셋 |
| **워크플로우** | 복잡한 작업의 단계별 실행 계획 템플릿 |
| **워크스페이스** | 채팅 세션을 그룹화하는 폴더 |
| **세션** | 하나의 채팅 대화 단위 |
| **전역 메모리** | 모든 세션에 적용되는 메모리 |
| **로컬 메모리** | 현재 세션에만 적용되는 메모리 |
| **사고 과정** | AI가 답변 생성 전 수행하는 내부 추론 단계 |
| **신뢰도** | AI 답변의 확신 정도 |
| **계획 카드** | 복잡한 요청 시 표시되는 실행 계획 UI |
